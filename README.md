# 📈 Time Series Analysis with Cryptocurrency  

## 📌 Project Overview  
This repository contains a **team project on time series analysis of cryptocurrency data**, developed as part of the **Data Science and Analytics Internship at Amdox Technologies**.  

The project integrates real-time and historical cryptocurrency datasets, builds a structured SQL database, performs advanced analytics, and visualizes insights through interactive dashboards. The goal is to provide traders and investors with meaningful forecasts, volatility measures, and performance comparisons.
